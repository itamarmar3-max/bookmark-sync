ייצא סימניות ב-Samsung Internet: הגדרות ← סימניות ← ייצא לקובץ HTML

🔌 חיבור Supabase

הכנס את פרטי הפרויקט שלך. הם יישמרו רק על המכשיר שלך.

SQL שצריך להריץ ב-Supabase (SQL Editor):

CREATE TABLE bookmarks ( id UUID DEFAULT gen_random_uuid() PRIMARY KEY, user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE, title TEXT NOT NULL, url TEXT NOT NULL, favicon TEXT, folder_path TEXT[] DEFAULT '{}', domain TEXT, created_at TIMESTAMPTZ DEFAULT NOW(), hash TEXT UNIQUE ); ALTER TABLE bookmarks ENABLE ROW LEVEL SECURITY; CREATE POLICY "Users own bookmarks" ON bookmarks FOR ALL USING (auth.uid() = user_id); CREATE INDEX ON bookmarks(user_id); CREATE INDEX ON bookmarks(hash);
